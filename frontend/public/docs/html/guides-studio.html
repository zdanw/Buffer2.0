Studio

Studio is for **one-off generation** with phone previews before publishing.

Generation modes

|--------|--------|

Key options

  • **Scene reference** — use lifestyle photos from Products
  • **Vision prompt** — AI reads your refs and writes a detailed image prompt
  • **Realistic placement** — product on a surface with shadows vs floating hero shot
  • **Reference image count** — how many product photos to send (1–4)

Publish actions

  • **Publish** → Buffer immediately
  • **Save to Review** → draft for manual approval

Hover **(?)** tooltips on each control for examples.
