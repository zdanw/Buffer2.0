# Image models & credits

Platform **image credits** appear in the top bar. Each default image generation costs one credit.

## Bring your own key (BYOK)

Under **Image Models**:

1. Add a provider (e.g. Doubao) with your API key
2. Test connection
3. Set as default for your account

Automations can override the model per task.

## Credits

- Trial credits on signup
- Bonus credits for completing onboarding
- Monthly packs via **Account** subscription

Pipeline comparison in Studio uses **2 credits** per click.
