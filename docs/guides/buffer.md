# Buffer setup

![Buffer accounts](../frontend/public/docs/screenshots/buffer-accounts.png)

PulseForge publishes through Buffer. You need a Buffer account with connected social profiles.

## Steps

1. In Buffer: **Account → Developers** — create an app or access token
2. In PulseForge: **Buffer accounts** — paste token and test connection
3. **Brand kits** — bind the token to your brand (one token per brand)
4. Publish from Studio, Review, or enable auto publish on Automations

In-app: open Buffer accounts and follow the built-in token guide.
