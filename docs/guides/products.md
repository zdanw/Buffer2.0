# Products & reference images

![Products](../frontend/public/docs/screenshots/products.png)

## Image types

| Type | Use for |
|------|---------|
| **Product images** | Clear shots of the item (angles, details) |
| **Scene images** | Lifestyle photos — item in a real environment |

Upload both for best Studio results with **Scene reference** enabled.

## Visual setup

Tell PulseForge what kind of offering this is (physical product, software, service, etc.) so generated scenes stay realistic.

## Preferred reference

When you have multiple product images, mark one as **preferred** — Studio uses it first.

## Incomplete products

A banner appears if a product lacks images or required fields. Generation is blocked until fixed.
