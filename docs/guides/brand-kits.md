# Brand kits

![Brand management](../frontend/public/docs/screenshots/brand.png)

Brand kits define how PulseForge writes copy and handles logos. Products inherit these settings.

## What to configure

| Field | Purpose |
|-------|---------|
| Name | Identifies the brand in the selector bar |
| Voice & audience | Tone, reading level, who you're talking to |
| Hashtags & emoji style | Platform caption patterns |
| Words to avoid | Negative prompt for copy |
| Logo rules | Preserve / omit / composite logos in images |
| Buffer account | One token per brand for publishing |
| Vertical pack | Optional preset bundle for visual styles |

## Workflow

1. **Settings → Buffer accounts** — add your API token
2. **Brand** — create or edit a brand kit
3. Bind the Buffer account
4. Assign products to this brand in **Products**

See also: [Buffer setup](buffer.md), [Products](products.md)
