# Visual styles

![Visual styles](../frontend/public/docs/screenshots/visual-styles.png)

Visual styles are shared presets for image generation: scenes, lighting, composition, color mood, and more.

- Filtered by **product type** (from product category)
- Shared across your brands
- General presets seed automatically on first run

Link styles to products on the Products page, or let Studio pick compatible presets.

**Tip:** Combine scene reference photos with visual styles for the most accurate lifestyle images.
