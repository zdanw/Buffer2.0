# Review queue

![Review](../frontend/public/docs/screenshots/review.png)

Drafts from **manual automations** or **Studio → Save to Review** appear here.

## Workflow

1. Select a draft from the left list
2. Pick **one image** and **one copy variant**
3. Re-upload any image marked **Not on CDN**
4. Select target platforms
5. **Publish** or **Discard**

Published posts appear on the [Calendar](calendar.md).
